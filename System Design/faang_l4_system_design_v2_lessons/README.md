# FAANG L4 System Design — V2 Lesson Pack

This folder contains the full **46-session** curriculum.

## Recommended use

- Complete lessons in order.
- One high-quality session per study day is enough.
- If you miss a day, continue with the next unfinished session.
- Do not compress multiple lessons just to catch up.
- Sessions 1–26 are fundamentals.
- Sessions 27–40 are full design practice.
- Sessions 41–46 are timed unseen mocks.

## Final readiness gate

Completion is based on performance, not merely finishing Lesson 46.

Your latest three unseen mocks should each score **at least 32/40**, with no category below 2.

The core categories — requirements, APIs/data, HLD, trade-offs, and communication — should average at least 3/4.

## Principle

> **Fundamentals first. Practice second. Repeated unseen performance determines readiness.**
