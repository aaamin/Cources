## How to study

### Lessons 01–26 — fundamentals

Read top to bottom. Focus on explanations, worked examples, **Important** callouts, interview model answers, common mistakes, the **Short Revision Note**, and **Topics to Revise**.

Do not try to memorize technology names. Be able to explain:

```text
problem → mechanism → when to use → failure → trade-off → alternative
```

### Lessons 27–40 — reference designs

Read the full design once. Then close the file and derive your own design under a 45-minute timer. Do not memorize the diagram. The goal is to learn reusable patterns.

### Lessons 41–46 — mocks

These intentionally contain **no reference solution**. Run them timed and score with `score.md`.

## Recommended session time

- Fundamentals: 60–90 minutes
- Reference designs: 90–120 minutes
- Timed mocks: 45–55 minutes + 30–45 minute review

## Completion rule

Missing a day does not change the sequence. Continue with the next unfinished lesson. Track completion in `progress.md`.

## Readiness gate

You are ready when your **latest three unseen mocks** each score **32/40 or higher**, no category is below 2, and requirements/API-data/HLD/trade-offs/communication average at least 3/4.
